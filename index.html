Реалізація UI Елементів

1. Radiobutton (Перемикач)

Призначення: Дозволяє користувачеві вибрати лише один варіант із запропонованого списку (взаємовиключний вибір).
Коли використовувати: Вибір статі, спосіб оплати, тарифний план.
Особливість: Усі радіокнопки з однаковим name утворюють групу – вибір однієї скасовує інші.



2. Checkbox (Прапорець)

Призначення: Дозволяє вибрати один або кілька варіантів із набору, або бінарний вибір (так/ні).
Коли використовувати: Згода з правилами, підписка, фільтри товарів.
Відмінність від radiobutton: Кожен чекбокс незалежний – можна позначити всі, жодного або будь-яку комбінацію.



3. Text input (Текстове поле)

Призначення: Введення короткого тексту (один рядок) або великого тексту (textarea).
Типи: text – звичайний текст; email – пошта з валідацією; number – числа; url – веб-адреса; password – прихований текст; textarea – багаторядковий текст.
Атрибути: placeholder (підказка), required (обов'язкове), maxlength (обмеження).












4. Tabs (Вкладки)

Призначення: Організація контенту по секціях, перемикання без перезавантаження сторінки.
Перевага: Економить місце, групує споріднену інформацію.
Коли використовувати: Налаштування профілю, документація, панелі адміністратора.

Це вміст першої вкладки. Тут може бути будь-який HTML: текст, зображення, форми.

Це вміст другої вкладки. Вкладки дозволяють не перевантажувати сторінку.

Це вміст третьої вкладки. Можна додавати скільки завгодно вкладок.

5. Button (Кнопка)

Призначення: Ініціює дію при натисканні (відправка форми, збереження, запуск скрипта).
Типи: submit – відправляє форму; reset – очищає форму; button – довільна дія.
Стан: disabled – кнопка недоступна для натискання.

6. Text label (Текстова мітка)

Призначення: Підпис до елемента керування. Покращує доступність – клік по мітці фокусує пов'язаний input.
Важливо: Атрибут for мітки має збігатися з id елемента.
Нижче – лише приклади міток різного стилю (без полів).













7. Link (Посилання)

Призначення: Навігація на іншу сторінку, файл, email або частину поточної сторінки.
Атрибут target: _blank – нова вкладка; _self – поточна (за замовчуванням).
Види: зовнішні (https://), внутрішні (#anchor), email (mailto:), телефон (tel:).

8. Tooltip (Спливаюча підказка)

Призначення: Показ додаткової інформації при наведенні курсору.
Коли використовувати: Пояснення термінів, абревіатур, іконок без підписів.
Реалізація: Чистий CSS через :hover + абсолютне позиціонування.

9. Dropdown list (Випадаючий список)

Призначення: Список варіантів, з якого користувач вибирає один (або кілька).
Перевага: Економить місце порівняно з radiobuttons для великих списків.
Атрибут multiple: Дозволяє вибір кількох опцій (Ctrl/Cmd + клік).




10. Data grid (Таблиця даних)

Призначення: Відображення структурованих даних у вигляді рядків та стовпців.
Структура: <table> → <thead> (заголовки) + <tbody> (дані).
Доступність: <th scope="col"> допомагає скрін-рідерам.
